BCA23301T Computer Network
Module I

Introduction: Definition, goals, design issues, Network architecture. Models: OSI & TCP/IP. Network classification (LAN, WAN, MAN). Transmission Media: Twisted Pair, Coaxial cable, Fiber optic. Multiplexing, switching. Network devices: repeater, bridge, router, gateways.

Module II

Data Link Layer: Framing, Error control (Bit Error, causes, methods). Flow control: Stop & wait, sliding window, piggybacking. LAN Technology Protocols: Aloha, CSMA, CSMA/CD, Collision free protocols.

Module III

Network Layer: Features & design issues. Routing algorithms, congestion control. Internetworking concepts. Addressing: IP Addressing, subnet masking, IP protocols, NAT, Address Resolution Protocol (ARP).

Module IV

Transport Layer: Design issues, Transport layer addressing, buffering, multiplexing, recovery. TCP/IP suit: TCP & UDP network applications. Connection establishment, Connection release, TCP Header.

Module V

Application Layer: Introduction to application layer. Application layer protocols: Electronic mail, File transfer, remote login, WWW, Multimedia, Firewalls.

Text Books

1. Data Communication & Networking by Forouzan
2. Computer Network by Andrew S. Tenenbaum

Detailed Syllabus
BCA23302T Design and Analysis of Algorithms
Unit 1

Introduction: Role of Algorithms in computing, Time and Space complexity, Best case, Average cage and worst case analysis of algorithms.

Unit 2

Growth of functions: Asymptotic notation, Big Oh, Big Omega, Theta, Small Oh, Small Omega and their property.

Unit 3

Recurrences: Basic concept of Recurrence, Recursion tree method, Master method.

Unit 4

Divide and Conquer Algorithms: Analysis of Merge sort, Quick sort.

Unit 5

Greedy Algorithms: 0-1 Knapsack problem, Huffman codes, Activity selection problem.

Unit 6

Graph Algorithms: Breadth first search, Depth first search, topological sort, Kruskal and Prim’s Algorithm.

Unit 7

Introduction to NP completeness: P, NP and NPC problems.

Text Books

Introduction to Algorithms by T Cormen, C. Leiserson, R. Rivest, C. Stein

Detailed Syllabus
BCA23303T (Elective-II) Cyber Security
Module I

Introduction to Cyber Security: Importance and scope, threats, vulnerabilities, risk, exploit. Types of attackers, Cyber kill chain, defense-in-depth strategy, Security triad (CIA).

Module II

Network and System Security: Basics of TCP/IP, OSI model security. Attacks: IP spoofing, ARP poisoning, DNS attacks, DDoS. Firewalls, IDS/IPS, VPNs, OS security, endpoint protection, securing IoT.

Module III

Cryptography and Secure Communication: Symmetric/asymmetric encryption (AES, DES, RSA), Hash functions (SHA, MD5), PKI, SSL/TLS, Authentication (passwords, biometrics), Key management, Cryptographic attacks.

Module IV

Cyber Security Practices, Laws & Trends: Security policies (ISO 27001), Incident response, Risk analysis. Legal frameworks: IT Act 2000, GDPR, HIPAA. Ethical hacking overview, Zero Trust, Cloud Security, AI in Security.

Text Books

Cybersecurity for Beginners by Raef Meeuwisse; Principles of Information Security by M.E. Whitman

Detailed Syllabus
BCA23304T (Elective-II) Natural Language Processing
Module 1

Introduction to NLP, Applications (chatbots, search engines, sentiment analysis), tokenization, stop-word removal, stemming, and lemmatization.

Module 2

Basic Language Modeling & N-Grams: Unigrams, Bigrams, Trigrams, probability models, text prediction, and smoothing techniques.

Module 3

Syntax & Semantics: POS tagging, shallow parsing, dependency parsing, WordNet, lexical databases, and semantic similarity.

Module 4

Machine Learning for NLP: Naive Bayes text classification, TF, TF-IDF, Bag of Words vector representations, and sentiment analysis.

Module 5

Deep Learning in NLP: Word embeddings (Word2Vec, GloVe), Recurrent Neural Networks (RNNs), chatbots, and NLP ethics/bias.

Text Book

"Speech and Language Processing" by Daniel Jurafsky & James H. Martin

Detailed Syllabus
AECC-IV Basics of Electronics (Embedded Systems)
Module 1

Introduction to Embedded Systems: Concept, characteristics, components, Microprocessor vs. Microcontroller, applications (smart homes, IoT).

Module 2

Microcontrollers & Programming: Arduino/ESP32 architecture, GPIO, Embedded C/C++ programming, variables, loops, functions, LED & push-button programming.

Module 3

Sensors & Interfacing: Digital/analog signals, LDR, IR, temperature & ultrasonic sensors, buzzer, relay, LCD, and serial communication basics.

Module 4

Embedded Control Applications: Traffic light controller, automatic street-light, distance/temperature monitoring, Servo/DC motor control, security systems.

Module 5

Development & Simulation Tools: Arduino IDE, Wokwi/Tinkercad simulation, debugging, Serial Monitor, introduction to ESP32.

Module 6

IoT and Mini Projects: Introduction to IoT, connecting to Wi-Fi, sensor data monitoring via cloud/mobile, smart home applications.
